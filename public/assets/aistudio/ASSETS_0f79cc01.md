# Assets & Image Generation Guide
## Abdullah — Digital Marketing Specialist

## 1. Asset principles
Use a small number of purposeful, high-quality visuals. The site should feel personal and credible. Do not use generic stock photos of random business meetings, fake analytics dashboards, or fabricated client work.

## 2. Required assets
| Asset | Priority | Notes |
|---|---|---|
| Professional portrait | Optional / high value | Use Abdullah's own approved photo; do not generate a fake likeness |
| Hero background visual | Optional | Abstract editorial texture or geometric composition |
| Service icons | Required if used | Simple consistent line icons; SVG preferred |
| Project screenshots | Only when real projects exist | Use approved screenshots with private data removed |
| Favicon/wordmark | Required | Text-based ABDULLAH wordmark is acceptable |
| Open Graph image | Recommended | 1200 × 630 px branded composition |

## 4. Portrait handling
If Abdullah uploads a real portrait:
- Use the supplied photo without changing identity or facial features.
- Crop thoughtfully for the hero and About section.
- Keep edits natural and professional.
- Do not synthesize a replacement person.
- Provide descriptive alt text such as “Portrait of Abdullah” only if the image is actually him and he approves its use.

If no portrait is supplied, use the wordmark and abstract hero art. Do not invent a person.

## 5. Asset specifications
- Hero visual: 1600 × 1000 px or larger, WebP/AVIF preferred
- Project thumbnails: 1200 × 900 px, WebP preferred
- Open Graph: 1200 × 630 px
- Favicon: SVG or PNG, simple monogram/wordmark
- Icons: SVG, consistent stroke weight

## 6. File naming
Use descriptive lowercase names:
- `abdullah-hero-abstract.webp`
- `abdullah-seo-visual.webp`
- `abdullah-meta-ads-visual.webp`
- `abdullah-social-media-visual.webp`
- `abdullah-og-image.webp`
- `abdullah-favicon.svg`

## 7. Performance and accessibility
- Compress images and use responsive `srcset` where supported.
- Lazy-load below-the-fold images.
- Do not lazy-load the main hero image if it is the largest contentful element.
- Add useful alt text to meaningful images.
- Use empty alt text for purely decorative imagery.
- Avoid text embedded in images except for the social preview graphic.

## 8. Asset approval checklist
- [ ] Abdullah approves any portrait used.
- [ ] Project screenshots are authentic and safe to publish.
- [ ] No customer/private information appears in screenshots.
- [ ] Generated illustrations contain no fake data or brand marks.
- [ ] All images are optimized and have suitable alt behavior.
